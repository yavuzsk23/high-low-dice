# English
# Dice Duel C#
A simple, short 5-round console-based dice game written in C# where you compete against the computer.

## Usage
1. Run the program.
2. The game automatically rolls dice for both you and the computer for 5 rounds.
3. The highest roll wins the round. 
4. View the final score at the end.

# Türkçe
# Zar Düellosu C#
Bilgisayara karşı oynadığınız, C# ile yazılmış 5 rauntluk basit ve kısa bir konsol tabanlı zar oyunu.

## Kullanım
1. Programı çalıştırın.
2. Oyun, 5 tur boyunca siz ve bilgisayar için otomatik olarak zar atar.
3. En yüksek zarı atan turu kazanır. 
4. Oyun sonunda final skorunu görün.
